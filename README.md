# Sudolux

Sudolux es una iniciativa personal orientada al desarrollo de una aplicación web de Sudoku con una experiencia clara, progresiva y adaptable a diferentes dispositivos.

El proyecto busca ofrecer un espacio de entretenimiento basado en lógica, atención y resolución de problemas, manteniendo una interfaz sencilla y accesible para distintos tipos de usuarios.

## Iniciativa

Sudolux forma parte del ecosistema Neuronova Apps y se desarrolla como un proyecto personal e independiente de Gabriel Berrospi.

La propuesta nace con la intención de construir una aplicación de Sudoku que pueda crecer progresivamente en niveles, funciones y opciones de interacción sin perder claridad de uso.

## Propósito

El propósito de Sudolux es brindar una experiencia digital de Sudoku orientada al entretenimiento y a la práctica de razonamiento lógico mediante partidas organizadas por niveles de dificultad.

## Alcance

El desarrollo contempla progresivamente funciones relacionadas con:

- partidas de Sudoku con diferentes niveles de dificultad;
- validación de movimientos y resolución de tableros;
- ayudas y pistas de uso comprensible;
- seguimiento básico del progreso de juego;
- adaptación a dispositivos móviles y de escritorio;
- mejoras de accesibilidad y experiencia de usuario.

Las características pueden modificarse, ampliarse o reorganizarse conforme avance el desarrollo y las pruebas de la aplicación.

## Desarrollo

Sudolux se encuentra actualmente en etapa de desarrollo. La aplicación será construida de manera gradual, priorizando estabilidad, claridad de interacción y una experiencia de juego consistente antes de incorporar funciones adicionales.

## Ecosistema

Sudolux forma parte de [Neuronova Apps](https://neuronova-apps.github.io/), plataforma matriz que reúne diferentes aplicaciones web desarrolladas como proyectos independientes.
