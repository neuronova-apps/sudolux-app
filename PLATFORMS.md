# Plataformas de Sudolux

La página web de Sudolux funciona como acceso oficial y presentación del producto dentro del ecosistema NeuroNova Apps. No sustituye a la aplicación Android ni a la versión de Facebook Instant Games.

## Web

- Estado: disponible.
- Función: acceso web oficial y demostración del producto.
- URL: https://neuronova-apps.github.io/sudolux-app/

## Android / Google Play

- Proyecto Android: existente.
- Estado: beta y preparación de distribución.
- Enlace público de Google Play: pendiente.
- Cuando exista una ficha pública en Google Play, el enlace debe registrarse en `platforms.json` sin cambiar la URL de acceso web.

## Facebook Instant Games

- Plataforma contemplada: sí.
- App ID de Meta: `1385490019602584`.
- Enlace público para jugar: pendiente de confirmar.
- El botón o enlace público debe apuntar al juego accesible para usuarios, no al panel de desarrolladores ni al App ID.
