# Documentación de Sudolux

Este directorio reúne la documentación de proyecto de Sudolux.

## Estado actual

**Demo web funcional en desarrollo activo.**

La web ofrece contenido introductorio, reglas interactivas y una partida clásica 9 × 9 jugable. La aplicación móvil permanece como expansión futura del proyecto.

- [ALCANCE.md](ALCANCE.md) — alcance actual de la web y ampliaciones futuras.
